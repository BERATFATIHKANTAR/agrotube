# AgroTube 

AgroTube, tarımsal içeriklerin, rehberlerin ve uzman tavsiyelerinin paylaşıldığı, üreticiler ile tarım meraklılarını bir araya getiren bir platformdur.

---

## Özellikler

- **İçerik Akışı:** Tarımsal eğitim, ipuçları ve uygulamalı video/içerik paylaşımları.
- **Kategori Bazlı Keşif:** Ürün grubu, ekim/hasat teknikleri ve tarımsal ekipman kategorileri.
- **Topluluk ve Etkileşim:** Üreticiler arası bilgi paylaşımı ve yorumlar.
- **Kullanıcı Profilleri:** İçerik üreticileri ve çiftçiler için özel profil yönetimi.

---

## 🛠️ Teknolojiler

- **Mobil:** React Native / Expo, TypeScript
- **Backend:** Node.js / Express (veya Python / FastAPI)
- **Veritabanı:** PostgreSQL / Supabase / Firebase
- **Sürüm Kontrolü:** Git & GitHub
